# ☠️ One Piece — Grand Line

Um site temático sobre **One Piece**, desenvolvido utilizando exclusivamente **HTML**, sem CSS e sem JavaScript.

O projeto foi criado com o objetivo de explorar recursos básicos e avançados do HTML, além de demonstrar como criar um site com várias páginas interligadas por meio de links.

---

## 📖 Sobre o projeto

O site apresenta informações sobre o universo de *One Piece*, incluindo:

* História
* Personagens
* Tripulação dos Chapéus de Palha
* Frutas do Diabo
* Haki
* Ilhas
* Marinha
* Akuma no Mi
* Formulário de contato

Todas as páginas possuem um sistema de navegação que permite ao usuário acessar as diferentes partes do site.

## 🧭 Navegação

Todas as páginas possuem uma barra de navegação semelhante:

```html
<nav>
    <a href="index.html">Início</a> |
    <a href="historia.html">História</a> |
    <a href="personagens.html">Personagens</a> |
    <a href="tripulacao.html">Tripulação</a> |
    <a href="frutas.html">Frutas</a> |
    <a href="haki.html">Haki</a> |
    <a href="ilhas.html">Ilhas</a> |
    <a href="marinha.html">Marinha</a> |
    <a href="akuma-no-mi.html">Akuma no Mi</a> |
    <a href="contato.html">Contato</a>
</nav>
```

Dessa forma, o usuário consegue navegar entre todas as páginas sem precisar de JavaScript.

Utilize os links do menu para acessar as outras páginas.

## 🎯 Objetivo acadêmico

Este projeto demonstra a utilização de **HTML5** para construção de um site multipágina.

Os principais objetivos são:

1. Aprender a estruturar páginas HTML.
2. Utilizar elementos semânticos.
3. Criar links entre diferentes documentos.
4. Trabalhar com tabelas.
5. Criar formulários.
6. Utilizar diferentes tipos de `<input>`.
7. Utilizar recursos de acessibilidade, como atributos `alt` em imagens.
8. Organizar um projeto com múltiplos arquivos.
9. Explorar recursos avançados do HTML sem depender de CSS ou JavaScript.
